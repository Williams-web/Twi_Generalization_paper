# Error Analysis

The workbook contains up to 50 misclassified examples from E2 and E4. Manually assign an error category and add a short explanation. Suggested categories: code-switching, spelling/orthography, negation, slang, ambiguity, sarcasm/context, emoji/context, short/insufficient context, other, unclear.

Do not publish raw tweet text in the final paper unless permitted by the dataset license and ethics requirements; use examples sparingly and anonymize where appropriate.
