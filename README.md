# DCIT316 - Twi Cross-Dataset Generalization

**Topic:** How Generalizable Are Twi Sentiment Analysis Models? A Cross-Dataset Study of Ghanaian Social Media Sentiment

## Status
Dataset preparation and baseline experiments E1–E4 are implemented. Remaining work: interpret results, complete focused error analysis, synthesize literature, and write the paper.

## Structure
- `03_Data/raw/` — original dataset files; do not edit.
- `03_Data/processed/` — standardized datasets and reproducible splits.
- `05_Results/` — metrics, reports, confusion matrices and error files.
- `06_Error_Analysis/` — manual error analysis.
- `09_Documentation/` — research records and methodology.
- `notebooks/` — analysis and experiment notebooks.

## Run
Install `requirements.txt`, then run notebooks 01 and 02 from the `notebooks/` directory. Random state is fixed at 42.
